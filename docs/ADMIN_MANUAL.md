# Admin Operations Manual

## System: Rainbow Fashions Enterprise SaaS Command Center

---

## 1. Accessing Admin Console
- **URL:** `/admin`
- **Role Requirement:** User account with `role: "admin"` in MongoDB.

---

## 2. Key Administrative Capabilities

### 2.1 Product Catalog Moderation
- Navigate to **Admin Dashboard -> Products**.
- Approve, edit, feature, or soft-delete vendor-submitted product items.

### 2.2 User & Role Management
- Navigate to **Admin Dashboard -> User Management**.
- Promote accounts to `vendor` or `admin`, or block suspended accounts (`isBlocked: true`).

### 2.3 Financials & Analytics Export
- View live sales counters, average order value (AOV), and total revenue.
- Export sales reports in **CSV / PDF** format.
