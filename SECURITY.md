# Security Policy - Rainbow Fashions Enterprise SaaS

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting Vulnerabilities

If you discover a potential security vulnerability within Rainbow Fashions Enterprise SaaS, please do NOT disclose it publicly on GitHub issues.

Instead, please send an email directly to security team:
**Email**: `security@rainbowfashions.com`

Please include:
- Description of the vulnerability and potential impact.
- Steps to reproduce or proof-of-concept exploit payload.
- Affected endpoints or components.

We take security seriously and will acknowledge receipt of your vulnerability report within 24 hours and provide an estimated patch timeline.
